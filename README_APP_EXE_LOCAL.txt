VARIANTA DESKTOP LOCALA - app.exe

1. Intra in folderul proiectului.
2. Ruleaza dublu-click pe BUILD_APP_EXE_LOCAL.bat.
3. Dupa finalizare, porneste: dist\app\app.exe

Important:
- Aplicatia ramane locala pe laptop.
- Nu foloseste host public si nu trimite date pe internet.
- Se deschide intr-o fereastra de aplicatie prin Edge/Chrome app mode.
